# 风电场检修隔离与作业许可协调平台

源提示词编号：9。覆盖风机、箱变和线路隔离点、锁定与验电步骤、作业许可状态流、跨班组冲突检测、实时提醒、断线重连、失败操作重试和审计记录。

## 联动与离线合并规则

- **隔离点 → 复核联动**：隔离点为全局共享资源（如 BUS-A 母线刀闸），每次现场操作修订号 +1；引用该点的许可把复核时的点修订号快照（`IP-xxx@rN`）与当前值比对，一旦变化立即标记「复核自动失效 / 失效待重算」并写审计；重算通过前许可不能推进流程（仅值班负责人可重算）。
- **操作三要素**：每条步骤确认、隔离操作、复核与流程推进都带 `actor`（谁）、`source`（PAD/值班台）、`baseRevision`（基于哪个修订号）。
- **断网现场确认**：断网后步骤确认与隔离操作本地乐观执行并入待处理队列；恢复时以服务器影子状态为基线合并。
- **差异优先，不覆盖**：恢复时修订号不匹配的操作挂为冲突，UI 并排显示双方操作人/时间/来源/修订号，本地乐观改动回滚为服务器版本；可「基于最新修订重做」（新 clientId、新修订号）或「保留对方记录」。
- **幂等补传**：每个操作有 `clientId`，重复补传/重试在服务器与本地都只落一次审计。
- **待处理与重试**：合不上的操作留在队列（失败/冲突状态、尝试次数、最后错误），恢复在线后可单条重试，审计记录重试次数、确认人、时间与来源。
